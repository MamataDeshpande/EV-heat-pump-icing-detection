# EV Heat-Pump Icing Detection — Python / XGBoost Demo

**An independently written, non-confidential portfolio demonstration inspired by my master's research in Automotive Software Engineering.**

> **Synthetic demonstration only:** All data and model results in this repository are artificial. No Mercedes-Benz recordings, company code, internal sensor identifiers, calibration values, or original trained models are included. This is not production-ready automotive software.

## Problem and research idea

During heating, the outside heat exchanger of an EV heat pump extracts heat from ambient air. In cold and humid conditions, frost can accumulate and reduce heat transfer. This project demonstrates a supervised XGBoost approach to identify patterns in three generic numerical features:

| Input | Meaning |
| --- | --- |
| `suction_pressure_bar` | Low refrigerant pressure |
| `high_pressure_bar` | High refrigerant pressure |
| `compressor_speed_pct` | Synthetic compressor operating point |

Output: `0` = non-iced and `1` = iced (synthetic labels).

## Quick start

Requires Python 3.10 or newer.

```bash
python -m venv .venv
source .venv/bin/activate
# Windows: .venv\Scripts\Activate.ps1
python -m pip install -e .
python -m unittest discover -s tests -v

python -m icing_demo.synthetic --out data/synthetic_recordings.csv
python -m icing_demo.training --data data/synthetic_recordings.csv --out outputs/model
python -m icing_demo.predict --data data/synthetic_recordings.csv --model outputs/model --out outputs/predictions.csv
python -m icing_demo.plotting --data outputs/model/held_out_predictions.csv --out outputs/example_prediction.png
```

The repository includes no source dataset. Its reproducible artificial measurements are generated by `synthetic.py`. Generated CSVs and trained model artifacts are ignored by Git.

The saved `outputs/model/metrics.json` reports synthetic test accuracy, precision, recall, F1 and a confusion matrix. These results do not indicate real vehicle performance.

## Why use recording-level validation?

Automotive time-series observations from one drive can be correlated. A random sample split may overstate performance if nearly identical samples appear in both training and testing. This independent demonstration holds out *complete synthetic recordings*.

Some non-iced example recordings include artificially constructed restart-like changes in pressure and compressor speed. They demonstrate why false positives under dynamic conditions deserve additional validation.

## Optional MF4 support

An optional `asammdf` adapter is provided for files you are specifically authorized to process. It requires a user-supplied mapping from independent signal names to the three generic inputs:

```bash
python -m pip install -e '.[mf4]'
```

```python
from icing_demo.mf4_adapter import read_mf4

frame = read_mf4(
    "authorized_example.mf4",
    {
        "suction_pressure_bar": "ExampleSuctionPressure",
        "high_pressure_bar": "ExampleHighPressure",
        "compressor_speed_pct": "ExampleCompressorSpeed",
    },
)
```

No MF4 recording is distributed here. Verify your own data's units, permissions, and alignment before use.
